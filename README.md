1. Цель проекта
Разработать веб-приложение на Streamlit для прогнозирования статуса студентов (отчислен / выпустился / продолжает обучение) с использованием 6 моделей машинного обучения. Приложение позволяет загружать данные в формате CSV или вводить признаки вручную и получать предсказание в реальном времени.

2. Установка и запуск
Для работы приложения необходима установка библиотек: streamlit, pandas, numpy, matplotlib, seaborn, scikit-learn, lightgbm, tensorflow. Запуск осуществляется через команду streamlit run app.py. Рекомендуемая версия Python — 3.11, так как TensorFlow не поддерживает Python 3.14.

3. Используемые модели
В проекте реализовано 6 моделей классификации:

KNN (K-Nearest Neighbors) — классическая модель на основе ближайших соседей.

Gradient Boosting — ансамблевый метод бустинга.

LightGBM — продвинутый градиентный бустинг от Microsoft.

Bagging Classifier — ансамблевый метод бэггинга.

Stacking Classifier — ансамблевый метод стэкинга (объединение нескольких моделей).

Нейронная сеть — полносвязная сеть с подбором гиперпараметров через Keras Tuner.

Все модели обучены на датасете "Predict Students' Dropout and Academic Success" и сериализованы. Scikit-learn модели сохранены с помощью pickle, LightGBM — встроенным save_model(), нейронная сеть — в формате .keras.

4. Структура проекта
app.py — главный файл с кодом Streamlit-приложения (4 страницы).

ml_classification.csv — исходный датасет (39 колонок, 4424 записи).

requirements.txt — список зависимостей.

README.md — документация.

models/ — папка с 6 сериализованными моделями.

.vscode/ — настройки редактора.

Приложение содержит 4 страницы:

О разработчике — ФИО, группа, фото, тема РГР.

О датасете — описание признаков, распределение целевой переменной.

Визуализации — 5 графиков (распределение возраста, boxplot оценок, корреляционная матрица, семейное положение выпускников, влияние стипендии).

Предсказания — выбор модели, загрузка CSV или ручной ввод, вывод результата.
